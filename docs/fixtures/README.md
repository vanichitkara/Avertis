# Shared conformance fixtures

`protocol_fixtures.json` is generated by the Python simulator and consumed by
**both** implementations:

- `simulator/tests/test_fixtures.py`
- `mobile/test/protocol_conformance_test.dart`

They pin canonical JSON encoding, payload hashing, packet serialisation,
forwarding semantics and relay scoring. If these tests fail, the phone and the
simulator have drifted apart and packets from one will not be understood by
the other.

Regenerate after any protocol change, and re-run both suites:

```bash
cd simulator && .venv/bin/python -m pytest -q
```

```bash
cd mobile && cp ../docs/fixtures/protocol_fixtures.json test/ && flutter test
```
